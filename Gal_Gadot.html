前言導讀：當「亞裔」從地理座標淪為外貌色碼

在當代社會的語言系統中，「亞裔（Asian）」理應是一個以地理板塊為基準的索引標籤；然而在主流影視、好萊塢打光系統以及東亞大眾的日常直覺中，這個詞彙卻早已被嚴格「降維封裝」為單一的東亞面孔（黃種人外貌）。

這種認知錯置帶來了兩極化的荒謬景觀：一方面，生於亞洲西側、擁有黎凡特高加索骨架的蓋爾·加朵（Gal Gadot），因符合大眾對「外國人／白人」的視覺模板，其亞裔身分被系統自動過濾；另一方面，在香港經典殭屍電影中，源自亞洲西部的基督十字架被東亞社會順理成章視為「洋廟」與西洋專屬法力。

本專案旨在透過「體質人類學骨骼硬代碼」與「資訊架構中的符號封裝理論」，拆解影視工業與大眾文化如何聯手劫持生理現實，修復大腦在處理族裔、信仰與地理歸屬時的底層認知 Bug。

一、 消失的亞裔：蓋爾·加朵（Gal Gadot）生理與身分悖論

1. 《玩命關頭》封面的「無差別質感」

當來自以色列的 Gal Gadot 與歐裔的 Paul Walker 並肩出現在海報上時，兩者的生理訊號在視覺上達到了驚人的對稱。這種「違和感的消失」並非偶然，而是地中海高加索支系在演化上的必然結果：

  • 骨架標記： 兩人皆具備極高的鼻根點、發達的眉弓以及狹長的臉部幾何特徵。這些「解剖學硬代碼」在好萊塢的打光系統下被放大，形成了一種跨越國籍的 「綠色區塊視覺統一感」。
  • 膚色反射率： 在系列電影追求的古銅色質感下，Gal Gadot 天然的橄欖色肌膚與歐裔演員人工曬黑的色值（RGB Value）幾乎重合。
  • 認知 Bug： 因為她符合了台灣大眾對「外國人」的視覺預設，其「亞裔」的身分變數被系統自動判定為無效並過濾，使她成為大眾眼中「長得像白人的非亞洲人」。

二、 術語的「定義偏誤」：誰才是亞裔美國人？

每當我們一提到 「亞裔美國人（Asian American）」 時，社會認知的預設邏輯通常會立即聯想到東亞面孔（黃種人），如小杉健（Kane Kosugi）。

  • 視覺綁架： 大眾的字典裡，"Asian" 被高度「視覺符號化」。這種認知 Bug 導致我們在調用此變數時，會優先進行「外貌匹配」而非「地理索引」。
  • 被隱形的群體： 廣義上，Gal Gadot（西亞）與 Kane Kosugi（東亞）都是亞裔。但因為 Gal Gadot 的高加索骨架在視覺上被判定為「西方」，這導致她的亞裔身分在討論中被徹底忽略。
  • 權力偏見： 這說明了「亞裔」標籤在社會認知中已被窄化。只有長得像「預期中的亞洲人」才被賦予這個標籤；而長得像「西方人」的亞洲人，則會獲得一種視覺上的「身分豁免權」，被直接歸類為主流的高加索群體。

三、 林正英電影：影視符號對生理現實的劫持

1. 《驅魔道長》：「中西合璧」下的定義虛無與起源反諷

「中西合璧，天下無敵！」 —— 九叔（林正英）與吳神父（午馬）

這句影史經典台詞背後，隱藏著跨文化傳播中的認知斷層與符號劫持：

  • 影視符號的系統封裝： 在香港傳統影視脈絡中，大眾早已習慣藉由外在服裝與符號建立角色認同（例如《殭屍道長》中李道洪與麥景婷以華人面孔飾演西洋吸血鬼貴族夫妻）。吳神父一角亦是如此——即便缺乏西方高加索骨架，在神父黑袍、巨大十字架與拉丁經文的符號強行介入下，觀眾大腦便順理成章將其判定為「西方陣營」與歐美外來神權的化身。
  • 聖經人物的視覺同源性： 大眾直覺認為聖經人物是「外國人／白人」，是因為他們與歐洲人同樣具備深邃的高加索骨架。然而，這種視覺上的相似性常被誤解為「西方的證明」。事實上，西亞（亞洲）本就是白色人種的發源地之一，耶穌等人物具備高加索特徵是基於地理演化，而非因為他們是「歐洲人」。
  • 起源的歷史反差： 「中西合璧」這句話之所以耐人尋味，在於大眾直覺將九叔的茅山符咒與吳神父的十字架視為「東方 vs. 西方」的對立碰撞；然而追溯源頭，基督信仰與道教在歷史起源上其實皆誕生於廣義的亞洲大陸。基督教在歐洲經過長達兩千年的神學重塑、羅馬體系化與白人視覺包裝，使得同在亞洲的東亞社會早已認不出其原初脈絡，反而將這股源於亞洲西部的力量，視為必須透過「西洋符號」才能借用的外來體系。這是一種視覺上的 循環定義錯誤，將「生理特徵相似」誤認為「文化主權歸屬」。

2. 《一眉道人》：「洋廟」背後的傳播認知與起源荒謬

「我要燒了你這間『洋廟』...這叫邏輯你懂不懂啊？『洋婆』？」

保安隊長樓南光的這段台詞，表面上是市井小民的胡攪蠻纏，但深入剖析其語境會發現：將教堂稱為「洋廟」，對當時乃至現代不少東亞人而言，在認知邏輯上其實是極其自然的歸納。

  • 傳播路徑的認知錨定： 天主教（羅馬公教）隨近代歐洲傳教士傳入東亞，其組織中樞在羅馬，教堂建築亦承襲歐洲哥德或巴洛克風格。對於生活在傳統鄉土社會的庶民而言，將西洋人敬拜神祇的場所稱為「洋廟」，本質上只是一種「外國人的廟宇」之功能平移，完全符合其直觀生活經驗。
  • 歷史源頭的終極諷刺： 這種「洋」字標籤的合理性，恰恰反襯出歷史傳播的巨大反差——基督信仰與道教在最早的地理發源地上，同樣都是亞洲的產物。然而，經過歐洲長達千年的符號包裝與神權制度化，當這股源於亞洲西部的精神力量重返亞洲東部時，東亞庶民早已無法辨識其原初根源，只能將其作為徹底的「歐美舶來品」進行認知封裝。

四、 台灣社會認知 Bug：外國人定義的「選擇性渲染」

在台灣人的日常語境中，「外國人」 這一變數的渲染（Rendering）受到強烈的政治與階級過濾：

  • 種族視覺過濾： 提到「外國人」，腦中首選高加索支系。日本人與韓國人雖是異國，卻因「視覺相近」而被判定為同類；東南亞移工則因「階級偏見」，在語言習慣中被剝奪了「外國人」應有的異國情調。
  • 意識形態干擾： 中國大陸人在生理上是完全一致的同族，但在台獨份子等特定意識形態中，為了達成政治去連結，會強制在軟體層面將其賦予「外國人」的標籤，即便這與生理硬件的識別完全衝突。
  • 定義的荒謬： Gal Gadot 這種西亞亞裔被視為外國人，而美籍的小杉健（Kane Kosugi）卻因東亞面孔被當成自己人。這再次印證：大眾判斷的是「生理質感（Skin）」，而非「系統歸屬（Nationality）」。


// 技術報告：大腦認知編譯器的「命名空間封裝錯誤」（Namespace Bug Report）

大腦在解析「外國人」與「異教」時，並非查詢底層資料庫的「地理誕生地（Geographical Origin）」，而是直接透過外層 UI 與文化傳播路徑進行硬編碼封裝（Hardcoded Encapsulation）： 

// 大腦前端 UI 解析偽代碼 (Mental UI-Rendering Logic)
Class Individual {
    String GeographicalOrigin; // 實體底層：如 "West Asia / Israel"
    String CraniofacialBone;    // 生理硬體：如 "Caucasian (高鼻深眶)"
    String CulturalSymbol;      // 外部協定：如 "Cross / Church"

    Function ResolveIdentity() {
        // 嚴重 Bug：大腦自動忽略 GeographicalOrigin，僅以骨架與傳播中繼站作條件跳轉
        IF (this.CraniofacialBone == "Caucasian" || this.CulturalSymbol.isEuropeanRouted()) {
            AssignNamespace("Western.Mainstream"); // 賦予西方身分豁免權 (如 Gal Gadot)
            RenderAs("Foreigner / 洋");              // 封裝為舶來品 (如 天主教堂 -> 洋廟)
        } ELSE IF (this.CraniofacialBone == "Mongoloid") {
            AssignNamespace("Asian.Default");     // 僅此類別被賦予狹隘的「亞裔」標籤
            RenderAs("OneOfUs / 本地");
        }
    }
}

架構審查結論： 樓南光的「洋廟排他」與台灣大眾將 Gal Gadot 視為「非亞裔外國人」，本質上都是「傳播中繼站（歐洲）覆寫了源頭數據（亞洲）」引發的緩衝區溢位。大腦只讀取渲染後的視覺外殼（Skin），徹底遺失了地理與生物學的原始碼。

五、 結語：穿透符號假象，重構地理與生理的真實光譜

回顧從好萊塢巨作《玩命關頭》到香港九叔的《驅魔道長》，文化工業與傳播歷史對人類認知的塑造力令人驚嘆：

  • 「亞裔」標籤的去窄化：
    亞洲不是東亞單一群體的專有詞彙。從黎凡特海岸的高加索人種，到內陸平原的東亞人群，廣袤的亞洲大陸自古容納了多元的骨骼幾何與色素光譜。將「亞裔」等同於「單眼皮、平眉骨、黃皮膚」，本質上是全球商業資本為了便於分類管理所進行的視覺矮化。
  • 信仰符號的歷史還原：
    無論是林正英手中的道教桃木劍，還是吳神父高舉的基督教十字架，當我們撕去歐洲兩千年的白人神學包裝與拉丁外衣，兩者皆是在亞洲地理母體中孕育而生的精神產物。看清這一點，才能真正理解「中西合璧」背後那層同源異流的荒謬與深刻。
  • 終結 UI 審判：
    當我們習慣以「外貌像不像自己人」來決定誰是同胞、誰是外國人時，我們的大腦便永遠停留在樓南光「看見洋建築便喊洋廟」的簡化迴圈中。
